# file-manager

# How to Run the Application

To start the File Manager application, follow these steps:

1. Ensure you have Node.js installed on your machine. You can verify the installed version by running:

    node -v

2. Install the project dependencies by running:

    npm install

3. Start the application using the following command:

    npm run start --username=your_name

- Replace your_name with the desired username.
- For example, to run the program with the username Nat:

    npm run start --username=Nat

4. Upon starting, the application will display the following message:


    Welcome to the File Manager, your_name!
    You are currently in path_to_working_directory

5. To exit the program, you can either press Ctrl + C or enter the .exit command.
6. Upon exiting, the application will display a goodbye message:

    Thank you for using File Manager, your_name, goodbye!
